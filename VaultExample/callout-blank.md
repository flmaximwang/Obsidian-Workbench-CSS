# 👻 Callout Blank — 不可见容器

> **测试目标**: 验证 `[!blank]` 作为不可见布局容器 —— 无边框、无背景、无图标，仅提供结构和间距

---

## 场景 1: 网格中的空白容器

当需要在 `[!grid]` 中放置裸文本（非 callout 子项）时，用 `[!blank]` 包裹：

> [!grid|3]
>> [!blank]
>> **左列**
>>
>> 这是 `[!blank]` 包裹的文本，视觉上没有边框。
>
>> [!blank]
>> **中列**
>>
>> 列表：
>> - A
>> - B
>
>> [!blank]
>> **右列**
>>
>> ```python
>> # 代码在 blank 内
>> x = 1
>> ```

## 场景 2: 占位间距

`[!blank]` 可作为不可见的间距容器，在不同内容块之间创建空白间隔：

> [!blank]
> *（这个 blank 在渲染时完全不可见）*

## 场景 3: 嵌套布局结构

利用 `[!blank]` 构建任意多层布局结构：

> [!grid|2]
>> [!blank]
>> > [!note] **嵌套 note**
>> > 通过 blank 包裹后放入网格
>>
>> 更多内容
>
>> [!blank]
>> > [!warning] **嵌套警告**
>> > 同样通过 blank 包裹
>>
>> ```python
>> def blank_test():
>>     pass
>> ```

## 场景 4: 行内组合

> [!grid|4]
>> [!blank]
>> **A**
>
>> [!blank]
>> **B**
>
>> [!blank]
>> **C**
>
>> [!blank]
>> **D**

## 场景 5: 仅用于结构

> [!blank]
> - 这个 `[!blank]` 内只有列表
> - 不显示任何 callout 装饰
> - 布局上等同于普通段落

> [!info] 使用场景
> 当你想利用 callout 的布局能力（网格、卡组）但 **不希望** 看到任何 callout 视觉样式时，使用 `[!blank]`。它在渲染上等同于一个 div。
